# 站点技术栈概览

本网页基于静态站点构建，借助现代前端工具与 Minecraft 风格 UI，实现了沉浸式的文档浏览与方块展示体验。

## 核心技术

| 技术 / 库 | 用途 | 说明 |
|----------|------|------|
| **Three.js** | 3D 渲染引擎 | 用于在 `<mc-block>` 自定义元素中绘制等轴测方块模型，支持纹理、颜色图（grass/foliage）和模型继承。 |
| **marked.js** | Markdown 解析器 | 将 `.md` 文档渲染为 HTML，支持代码高亮扩展。 |
| **highlight.js** | 通用代码高亮 | 为除 `mcfunction` 外的多种编程语言提供语法高亮。 |
| **mcfunction-highlight** | Minecraft 函数语法高亮 | 专为 `mcfunction` 代码块设计，支持命令、选择器、NBT 等关键词高亮。 |
| **Giscus** | 评论系统 | 基于 GitHub Discussions 实现页面评论，支持暗色主题与反应互动。 |
| **原生 Web Components** | 自定义元素 `<mc-block>` | 封装 Three.js 渲染逻辑，实现声明式方块展示，支持 `size` 属性调节。 |
| **Fetch API + 动态路由** | 文档加载与导航 | 通过 `collections` 参数支持多文档集，侧边栏树形目录自动展开/折叠，并生成“上一章/下一章”导航。 |
<br>

## 文档系统架构

- `collections.html`：独立集合导航页，读取 `docs/collections.json` 展示所有文档集卡片。
- `template.html`：通用文档阅读页，根据 URL 参数 `?collection=xxx&page=yyy` 动态加载对应集合的 `index.json` 和 `.md` 文件。
- **目录支持多级嵌套**：每个集合的 `index.json` 采用 `tree` 数组，可定义无限层级文件夹与文档，侧边栏递归渲染并支持交互折叠。
<br>

## 样式与设计

- **全局** `style.css`：提供暗色主题、导航栏、卡片网格、合成表等 Minecraft 风格 UI 组件。
- **像素级纹理处理**：通过 `image-rendering: pixelated` 保留方块纹理的块状特征。
- **响应式布局**：移动端适配侧边栏与文档内容。
<br>
---

## 第三方服务

- **GitHub Pages**：托管站点与静态资源。
- **jsDelivr CDN**：加速 `marked.js`、`highlight.js` 等库的加载。
- **Giscus**：评论数据存储于 GitHub 仓库的 Discussions 中。
<br>
---

## 扩展性设计

- 所有自定义元素（`<mc-block>`）均支持未来扩展（如添加动画、交互）。
- 文档集合可自由增删，只需维护 `collections.json` 与对应文件夹内的 `index.json`。
- 代码高亮支持多语言，且 `mcfunction-highlight` 与 `highlight.js` 并存不冲突。
