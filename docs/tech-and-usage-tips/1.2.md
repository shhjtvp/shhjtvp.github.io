# 站点技术栈概览

这是一个纯静态的个人站点：首页有进入动画与滚动分页，文档部分自带 Markdown 渲染，
方块展示则由 `mc_textures/` 里的材质包实时渲染。

没有构建步骤 —— 所有页面都是手写的 HTML / CSS / 原生 ES Module，推到仓库即上线。

---

## 核心技术

| 技术 / 库 | 用途 | 说明 |
|----------|------|------|
| **Three.js r160** | 3D 渲染引擎 | `<mc-block>` 的渲染核心：父模型继承、`elements[].rotation`（含 `rescale`）、`faces[].rotation`、`tintindex` 染色、`shade:false` 全亮、`.mcmeta` 动态纹理。 |
| **JSZip** | 读取材质包 | 浏览器里直接解压 `mc_textures/*.zip`，按包内路径取模型与纹理。 |
| **marked.js** | Markdown 解析器 | 把 `.md` 渲染成 HTML，并额外实现了脚注（`[^1]`）。 |
| **highlight.js** | 通用代码高亮 | 除 `mcfunction` 外的语言都走它。 |
| **mcfunction-highlight** | MC 命令高亮 | 专门给 `mcfunction` 代码块做命令、选择器、NBT 高亮。 |
| **Giscus** | 评论系统 | 基于 GitHub Discussions，暗色主题、中文界面。 |
| **原生 Web Components** | `<mc-block>` | 把整套渲染逻辑封成自定义元素，写 `<mc-block size="200px">grass_block</mc-block>` 就能出图。 |
| **原生 CSS** | 视觉与交互 | `backdrop-filter` 毛玻璃、`@property` 驱动的缓慢自转、`scroll-snap` 整页分页。 |
| **Fetch + 动态路由** | 文档加载与导航 | `template.html?collection=xxx&page=yyy` 按需取 `index.json` 与 `.md`，侧边栏树形目录自动展开。 |

## 首页

首页由 `/css/home/` 下两个样式表与 `js/home.js` 负责，导航栏样式则留在共享的 `css/style.css`。

**进入动画**（单击正中 logo 触发，约 3 秒）：

1. 整页只有正中央的 logo，单击后先轻微放大；
2. 用 FLIP 飞到左上角导航栏 logo 的位置并缩放到同等大小（实测偏差 0.16px）；
3. 黑幕淡出，同时以 logo 为中心扩散一个蓝环、渐变为红并铺满整页；
4. 红环一边继续外扩一边淡出，首页内容同时以更长的曲线浮现，首屏元素再依次错开一点。

> 两个容易踩的点：光环的图层必须压在内容之上、**导航栏之下**，否则红环扩散时会把导航栏糊住；
> 扩散要用 `width/height` 而不是 `transform: scale()`，不然 3px 的描边放大几十倍会变成一堵厚墙。

**滚动分页**：原生 `scroll-snap` 整页吸附，滚轮即翻页，右侧指示点可跳转。
每一页固定一屏高并允许页内滚动 —— 否则内容一旦超过一屏，多出来的部分会被吸附回页首、永远看不到。

**头像与社交环绕**：头像圆形裁切，8 个社交按钮环绕在圆周上，整圈以 90 秒一圈缓慢自转
（用 `@property` 注册 `--orbit-spin` 让它可参与动画，子项末尾再反向旋转把图标转正）；指针进入时暂停自转，方便点击。

**光标光晕**：平时光标下有一层淡淡的蓝光，按住鼠标时交叉淡入红色。蓝、红两层径向渐变叠放，
靠透明度切换 —— CSS 渐变本身没有过渡。

## 方块渲染器

`<mc-block>` 直接吃 Minecraft 材质包，默认用精简包 `mini-26.2`（约 33 KB，只含站点用到的资源），
精简包里没有的方块会自动回退到完整包。

- **模型**：递归解析 `parent`、`#纹理变量`、元素的 `from/to/faces`、`rotation`（元素级与面级）、`shade`
- **纹理**：按 MC 的约定对齐 UV 与 `flipY`，`tintindex` 决定这一面是否用颜色图染色
- **动画纹理**：识别「竖排长条」纹理（例如 16×128 = 8 帧），读取同名 `.mcmeta` 的 `frametime` / `frames`；
  用 `texture.repeat/offset` 一次只采样一帧，靠 `requestAnimationFrame` 推进 offset，不需要重新上传纹理；
  带 `interpolate` 的会在加载时插值展开成 8 倍帧率
- **性能**：只有真用到动画纹理的方块才开渲染循环，离屏或标签页隐藏时自动暂停

## 文档系统

- `collections.html` 读 `docs/collections.json` 列出所有文档集；
- `template.html` 是通用阅读页，按 `?collection=&page=` 加载对应集合的 `index.json` 与 `.md`；
- 目录支持任意层级嵌套，递归渲染成可折叠的树，当前文档所在分支自动展开；
- 正文由 marked.js 渲染，另外实现了脚注悬浮提示与「上一章 / 下一章」导航；
- 每篇文档底部是 Giscus 评论区，数据存在 GitHub Discussions 里。

## 依赖与部署

- 前端库全部本地化在 `js/vendor/`，页面不依赖任何外部 CDN（CDN 只在本地文件缺失时兜底），
  这样即便访问不了 cdnjs 之类的源，站点样式与渲染也不会整体失效；
- 站点由 **GitHub Pages** 托管，部署分支是 `main`，推上去即生效；
- 材质包精简版由 `tools/build-mini-pack.mjs` 生成：扫描站点用到的方块，
  从完整包里抽出对应模型、纹理、颜色图与 `.mcmeta`，同时输出一份未压缩目录作为回退。
